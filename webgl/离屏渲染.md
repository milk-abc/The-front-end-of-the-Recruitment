离屏渲染是把画面先渲染到一张"纹理图片"里，而不是直接画到屏幕上。

##### 一、正常渲染(屏幕渲染)

一般的threejs渲染流程：

render.render(scene,camera);

流程：3D场景->GPU渲染->canvas->浏览器屏幕

##### 二、离屏渲染

流程：3D场景->GPU渲染->RenderTarget(纹理)->其他用途[渲染结果不会直接显示，而是存到一张纹理里]

##### 三、Threejs 实现离屏渲染

核心对象: 

```
new THREE.WebGLRenderTarget()

// 示例
const renderTarget = new THREE.WEBGLRenderTarget(1024,1024);
render.setRenderTarget(renderTarget);
render.render(scene,camera);
render.setRenderTarget(null);
```

流程：

scene->renderTarget.texture->可以当贴图使用

##### 四、离屏渲染常见用途

##### 1.  后处理(Post processing)

例如：Bloom、HDR、景深、模糊

流程：场景->renderTarget->shader处理->屏幕

##### 2.  反射(镜面反射)

例如水面：先渲染场景->生成反射纹理->贴到水面

##### 3.  阴影贴图

例如阴影：光源视角渲染->深度纹理->用于阴影计算

##### 4.  屏幕截图

可以把渲染结果：导出图片

例如：

```
renderer.readRenderTargetPixels()
```

##### 5.  GPU计算

例如：粒子模拟，物理模拟

##### 6.  GPU Picking

每个物体渲染唯一颜色->读取像素->知道点击了哪个模型

##### 五、一个实际例子(镜子)

例如一个镜子：

步骤：相机A渲染场景—>渲染到RenderTarget->把RenderTarget.texture贴到镜子

效果：镜子显示场景反射

##### 六、离屏渲染 vs 屏幕渲染

屏幕渲染： canvas

离屏渲染：纹理
